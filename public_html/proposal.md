## Project Name: YouTube Video Watchlist
### Project Summary:
This app lets users browse YouTube videos stored in the project database and save/unsave them to a personal watchlist (favorites). Admins can fetch and manage YouTube channel/video data via the YouTube API (and also create/edit/delete records manually). The system includes authentication, role-based access (Admin vs non-admin), CRUD pages for API entities, and a many-to-many user↔video association.
